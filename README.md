# 🎮 Videogames Passwords

Repositorio para almacenar contraseñas, códigos de guardado y passwords de juegos clásicos (Sega Genesis, SNES, NES, etc.) para no perderlos y acceder a ellos rápidamente.

---

## 🕹️ Lista de Juegos

* ⚽ [AWS Pro Moves Soccer (Sega Genesis)](./aws-pro-moves-soccer.md)

---

## 📋 Estructura de cada archivo

Cada juego cuenta con su propio archivo `.md` estructurado de forma simple con:
* Nombre del juego y plataforma.
* Nombre del equipo / jugador / nivel.
* Contraseña formateada en un bloque ejecutable/copiable.
